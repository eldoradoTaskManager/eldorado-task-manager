2. Privacy Policy
This policy outlines how Eldorado Task Manager handles information.
Data Collection & Usage
• No Personal Data Collected: Eldorado Task Manager does not collect, log, store, or share any personal information, location data, or usage metrics.
• Device-Only Data: Any data you input into the app stays strictly on your physical device. It is never transmitted to an external server or shared with any third parties.
• No Third-Party Analytics/Tracking: This app does not use any third-party SDKs, analytics libraries, or advertising networks that track user behavior.
Changes to This Policy
If this privacy policy changes in a future update (for example, if a cloud-sync feature is added), this page will be updated immediately.
